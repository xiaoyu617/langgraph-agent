LangChain is an open-source framework designed to simplify the development of applications powered by large language models (LLMs). It provides a modular approach to building LLM applications, supporting chains, agents, tools, memory, and integration with LangGraph for workflow orchestration. LangChain supports multiple LLM providers including OpenAI, Anthropic, and open-source models. Key features include: prompt templates, output parsers, document loaders, text splitters, vector stores, and retrievers.
