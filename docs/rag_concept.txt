Retrieval-Augmented Generation (RAG) is a technique that combines information retrieval with text generation. It works in three steps: 1) Embed the user query into a vector, 2) Search a vector database for similar documents, 3) Feed the retrieved documents as context to an LLM to generate a grounded response. RAG reduces hallucinations by ensuring the LLM's output is based on retrieved factual information rather than solely on its training data.
