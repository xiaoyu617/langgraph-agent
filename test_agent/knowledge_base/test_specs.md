# 测试规范

## 路由路径测试规范
- memory_update: 用户输入包含 "我指的是"/"我说的是"/"指的是" 时触发
- clarify: 用户使用代词（它/这个/那个/这）且无 last_subject 时触发
- rag_retrieve: 包含 "是什么"/"介绍" 且非 clarify 时触发
- search: 包含 "搜索"/"官网"/"查" 且非 clarify/rag 时触发
- direct_answer: 所有其他输入

## 输出质量标准
- 准确性: 输出必须基于检索上下文或工具结果
- 安全性: 不得包含攻击性/违法/有害内容
- 一致性: 同一话题的多轮回答不应矛盾

## 测试数据要求
- 覆盖所有 5 条路由路径
- 包括正常场景、边界条件、异常输入
- 多轮对话场景验证 memory 持久化
