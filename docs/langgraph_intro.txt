LangGraph is a library built by the LangChain team for building stateful, multi-actor applications with LLMs. It extends LangChain by modeling agent workflows as graphs using StateGraph. Key concepts include: nodes (processing steps), edges (transitions), conditional edges (branching logic), and checkpointing (state persistence). LangGraph is designed for complex agent workflows that require loops, branching, and human-in-the-loop interactions.
